더 빠르게 작업하고, 더 똑똑하게 자동화하며, 시간을 되찾으세요.

Gemini Power Kit은 AI 채팅을 고성능 작업 공간으로 바꿔 줍니다.
단순한 대화 이상의 기능을 원하는 사용자를 위해 반복적인 수작업을 줄이고, 집중을 유지하는 데 필요한 전문적인 구조를 제공합니다.

주요 기능
⚡ QUICK FOLLOW-UP — 선택하고 바로 질문
복사와 붙여넣기의 번거로움을 줄입니다. 선택한 텍스트에서 바로 Gemini와 상호작용하세요.
  ● 즉시 후속 질문: 아무 텍스트나 선택하고 바로 질문할 수 있습니다.
  ● 맞춤 프롬프트 라이브러리: "요약" 또는 "설명" 같은 나만의 바로가기를 만들어 한 번의 클릭으로 실행하세요.

🗂️ CHAT OUTLINE — 길을 잃지 마세요
모든 프롬프트를 보고, 원하는 곳으로 이동하고, 리서치용으로 아웃라인을 고정하세요.
  ● 모든 프롬프트 보기: 대화 전체를 한눈에 바로 확인할 수 있습니다.
  ● 이동하고 고정: 채팅의 원하는 위치로 이동하고 리서치용으로 아웃라인을 고정하세요.

🗑️ BULK DELETE — 고정한 채팅은 그대로 두고 Gemini 채팅 정리
임시 대화를 묶어서 삭제하면서 고정한 채팅은 정리 대상에서 제외할 수 있습니다.
  ● 고정 채팅 한 번에 제외: “고정 제외”를 켜면 최근 대화 묶음을 선택할 때 고정된 대화를 자동으로 건너뛰므로, 일일이 선택 해제할 필요가 없습니다.
  ● 알맞은 묶음 삭제: 최근 채팅 10개, 20개, 30개 또는 50개를 선택하고 필요하면 개별 조정한 뒤, 확인하고 삭제 진행 상황을 확인하세요.

🎨 비주얼 테마 — 나만의 Gemini 만들기
작업 공간을 바꾸고 Gemini를 더 개인화하세요.
  ● 멋진 색상 프리셋: 다양한 생동감 있는 테마로 더 개인적인 환경을 만드세요.
  ● 맞춤 배경화면: 개인 배경과 세련된 글래스 효과로 경험을 높이세요.
  ● 채팅 레이아웃: Chat Width와 Input Width를 Default, %, 또는 px로 조정하고, 동기화, 메시지 정렬, 전체 너비 메시지를 설정하세요.

🎭 GEM 아바타 — 각 Gem을 바로 구분
각 Gemini Gem에 전용 아바타를 설정해 목록과 채팅에서 바로 알아볼 수 있습니다.

🔔 답변 완료 알림 — 자리를 비워도 안심
답변, 이미지, 동영상, Deep Research 보고서가 끝나면 데스크톱 알림으로 알려줍니다.
  ● 완료 알림: 답변, 이미지, 동영상, Deep Research 보고서가 준비되면 데스크톱 알림을 받습니다.
  ● 클릭해서 돌아가기: 원래 채팅으로 돌아오고, 기본 또는 사용자 지정 사운드도 사용할 수 있습니다.

🔗 CHAIN PROMPT — 복잡한 워크플로 자동화
재사용 가능한 프롬프트 시퀀스를 변수와 시각적 편집기로 단계별 관리할 수 있습니다.
  ● 유연한 시퀀스: 동적 변수를 사용해 재사용 가능한 프롬프트 흐름을 만드세요.
  ● 편집하고 추적하기: 드래그 앤 드롭으로 편집하고 진행 상황을 단계별로 확인하세요.

💎 매끄러운 경험
● 스마트 탭 제목: 채팅 제목에 맞춰 브라우저 탭 이름을 자동으로 변경해 여러 Gemini 세션 사이를 쉽게 전환할 수 있습니다.
● 새 탭에서 미디어 열기: Library 갤러리에서 항목을 새 탭으로 열고 현재 위치를 유지한 채 결과를 확인하세요.

개인정보 보호 우선
🔒 모든 처리는 사용자의 기기에서 로컬로 이루어집니다. 데이터는 기기를 벗어나지 않습니다.

성능
- 가볍고 깔끔함: 기본 UI와 자연스럽게 어울리는 미니멀한 디자인.
- 라이트 모드와 다크 모드를 모두 아름답게 지원합니다.
