Sammeln Sie mit Multi-Ask Fragen zu verschiedenen Textstellen und senden Sie sie zusammen mit den Originalpassagen. Passen Sie das Gemini-Design an und springen Sie über die Chat-Gliederung zu früheren Prompts. Zum Aufräumen wählen Sie die Chats aus, die Sie gesammelt löschen möchten.

DESIGNS, HINTERGRÜNDE & LAYOUT
• Legen Sie ein eigenes Hintergrundbild und passende Farben fest, indem Sie ein Bild außerhalb des Promptfelds auf die Seite ziehen.
• Verbreitern Sie den Chat für mehr Platz für Code und Tabellen. Passen Sie die Breite des Promptfelds separat an oder koppeln Sie sie an den Chat.

MULTI-ASK — FRAGEN BEIM LESEN SAMMELN
• Markieren Sie beim Lesen Textstellen und schreiben Sie zu jeder eine eigene Frage.
• Senden Sie die Fragen zusammen mit den ursprünglichen Textstellen in einer Nachricht, ohne den Kontext selbst kopieren und zusammensetzen zu müssen.

CHAT-GLIEDERUNG
Behalten Sie in langen Unterhaltungen den Überblick. Sehen Sie eine Gliederung Ihrer Prompts, springen Sie zu einem früheren Beitrag oder heften Sie die Gliederung während der Arbeit an.

CHATS GESAMMELT LÖSCHEN
Wählen Sie mehrere aktuelle Unterhaltungen aus, passen Sie die Auswahl an und bestätigen Sie das Löschen. Aktivieren Sie „Angeheftete ausschließen“, damit angeheftete Chats bei der Auswahl übersprungen werden.

PROMPT-KETTEN
Speichern Sie wiederholbare Aufgaben mit mehreren Schritten als Prompt-Ketten. Nutzen Sie Variablen für unterschiedliche Eingaben, ordnen Sie Schritte im Drag-and-drop-Editor und verfolgen Sie den Fortschritt.

ANTWORTBENACHRICHTIGUNGEN
Aktivieren Sie Desktop-Benachrichtigungen, wenn eine Antwort, ein generiertes Bild oder Video oder ein Deep-Research-Bericht bereit ist. Klicken Sie auf eine Benachrichtigung, um zum Chat zurückzukehren.

WEITERE ALLTAGSFUNKTIONEN
• Vergeben Sie individuelle Avatare für einzelne Gems.
• Lassen Sie Browser-Titelleisten die Titel Ihrer Unterhaltungen anzeigen.
• Öffnen Sie Medien aus der Library in einem neuen Tab und behalten Sie Ihren Platz in der Galerie.

DATENSCHUTZ
Gemini Power Kit verarbeitet seine Erweiterungsfunktionen in Ihrem Browser und sendet Ihre Unterhaltungen nicht an vom Entwickler kontrollierte Server. An Gemini gesendete Anfragen werden von Google-Diensten verarbeitet. Einige Einstellungen können je nach Browsereinstellungen über Ihr Browserkonto synchronisiert werden.
