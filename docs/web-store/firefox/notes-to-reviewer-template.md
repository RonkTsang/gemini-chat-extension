# Notes to Reviewer Template

Use this template for the AMO **Notes to Reviewer** field. Replace every
`{{...}}` placeholder with the exact version, tag, and GitHub Actions run used
for the submitted Firefox package.

```text
Public source repository:
https://github.com/RonkTsang/gemini-chat-extension

Submitted release tag:
https://github.com/RonkTsang/gemini-chat-extension/releases/tag/v{{VERSION}}

Source package for this submitted version:
https://github.com/RonkTsang/gemini-chat-extension/releases/download/v{{VERSION}}/gemini-extension-{{VERSION}}-sources.zip

Submitted Firefox package:
https://github.com/RonkTsang/gemini-chat-extension/releases/download/v{{VERSION}}/gemini-extension-{{VERSION}}-firefox.zip

GitHub Actions build run:
{{GITHUB_ACTIONS_RUN_URL}}

This add-on is built with WXT, Vite, React, and TypeScript. The submitted
Firefox package was generated by GitHub Actions from the v{{VERSION}} release
source.

Build environment:
- OS: Linux (GitHub Actions ubuntu-latest)
- Node.js: 22.14.0
- pnpm: 10.13.1

Build steps:
1. Download and extract the source package:
   gemini-extension-{{VERSION}}-sources.zip

2. From the extracted source package root, run:
   corepack enable
   corepack prepare pnpm@10.13.1 --activate
   pnpm install --frozen-lockfile
   RELEASE_VERSION={{VERSION}} pnpm run zip:firefox

Expected output:
.output/gemini-extension-{{VERSION}}-firefox.zip

The Firefox-specific manifest settings are generated from wxt.config.ts. The
Firefox build uses Manifest V2 and includes browser_specific_settings.gecko
with ID {{FIREFOX_GECKO_ID}}, strict_min_version 140.0, notifications,
webRequest, webRequestBlocking, and host access for gemini.google.com.

The extension does not use remotely hosted code. Extension scripts, styles,
images, and bundled assets are included in the build output. Dependencies are
installed from pnpm-lock.yaml.
```
