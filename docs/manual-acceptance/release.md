本清单是发布前的人工验收入口，所有功能统一从本文件执行；不包含 CI、类型检查或自动化测试项目。

## Theme Bloom

- ☐ P0｜功能：安装后首次外部图片拖放
  - 操作路径：全新安装扩展后打开已登录 Gemini，不刷新页面，从文件管理器将有效图片拖到输入区外。
  - 预期结果：第一次拖放立即完成主题与背景应用，Bloom 起点接近拖放位置，无需刷新或重试。

- ☐ P0｜功能：刷新后首次外部图片拖放
  - 操作路径：刷新已安装扩展的 Gemini 页面并等待稳定，从文件管理器将有效图片拖到输入区外。
  - 预期结果：第一次拖放正常完成主题与背景应用，动画起点和收尾状态正确。

- ☐ P0｜功能：保护 Gemini 原生上传
  - 操作路径：将有效图片从文件管理器拖入 prompt 输入框或其原生附件区域。
  - 预期结果：Gemini 显示原生附件预览并可发送、移除或取消；不触发 Theme Bloom，也不改变主题。

- ☐ P0｜功能：禁用行为
  - 操作路径：关闭 Theme Bloom 后，将有效图片拖到输入区外，再拖入 prompt 输入框。
  - 预期结果：输入区外不触发换肤或 Bloom；prompt 输入框仍由 Gemini 原生上传处理。

- ☐ P0｜功能：输入校验与状态完整性
  - 操作路径：启用 Theme Bloom，分别拖入无效格式、多文件和超出大小限制的文件到输入区外。
  - 预期结果：每次均被明确拒绝或忽略；已有主题与背景不变，不残留遮罩、临时样式或卡住的过渡。

- ☐ P0｜功能：降低动效与无 View Transition 降级
  - 操作路径：分别启用 `prefers-reduced-motion: reduce`，以及在不提供 `document.startViewTransition` 的环境中拖入有效图片。
  - 预期结果：前者不播放不必要的长动画，后者显示可见的降级效果；两种情况下主题与背景都完成应用，页面保持可交互。

- ☐ P0｜功能：刷新后主题与背景持久化
  - 操作路径：成功完成一次换肤后重新加载 Gemini 页面并等待完成。
  - 预期结果：已选主题与背景恢复，无异常 Bloom 遮罩；页面可继续使用，刷新后的首次外部拖放仍正常。

## 验收原则

- 只验证用户可感知的关键路径，不把内部实现或 CI 项目写入人工清单。
- P0 是发布门槛；P1 可作为后续回归项，不应与 P0 混淆。
- 预期结果必须可观察、可判断，避免使用“应该正常”等无法验收的表述。
- 安装后首次使用、刷新后首次使用、禁用状态和失败降级优先覆盖，因为这些路径最容易出现用户侧回归。
- 失败项不通过勾选掩盖；必须保留证据、复现步骤和发布阻塞判断。
