Use the **↑** and **↓** buttons next to **Chat Outline** to move one prompt at a time through the current Google Gemini conversation. Each jump takes you to one of your messages, with Gemini’s reply directly below it.

## Where to find the arrows

[Install Gemini Power Kit](/guide/install/), then open a conversation in [Gemini](https://gemini.google.com). If Gemini was already open during installation, refresh the tab. Look for the arrows next to the stacked-lines icon in the upper-left corner of the conversation area. You can use them with the outline panel closed.

## What the up and down buttons do

| Button | Between prompts | At the first or last prompt |
| --- | --- | --- |
| **↑ Previous prompt** | Jumps to the previous prompt. | **Scroll to top** takes you to the top of the conversation area. |
| **↓ Next prompt** | Jumps to the next prompt. | **Scroll to bottom** takes you to the bottom of the conversation area. |

The arrows work on prompts Gemini has loaded in the current chat. If an older prompt hasn’t loaded yet, scroll up to load more history and try again. In an empty chat, the arrows are hidden.

## Turn prompt navigation arrows on or off

Open Gemini Power Kit from the puzzle-piece entry in Gemini’s sidebar, then go to **Enhancements → Chat Outline**. The arrows are on by default when **Chat Outline** is enabled. If you see the **Show prompt navigation arrows** switch, you can use it to hide or show the buttons and keep using the outline list.
