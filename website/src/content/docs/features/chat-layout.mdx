## Customize the Space Around Your Gemini Conversation

**Chat layout** gives you direct control over the space used by a Gemini conversation, its prompt box, and your own messages. Use it when the default layout feels too narrow for comparison work, too wide for focused reading, or when you want the prompt box to line up with the conversation.

It is part of **Theme** customization, so your layout settings stay available even when you hide the quick shortcut.

## Where to Find Chat Layout

On [gemini.google.com](https://gemini.google.com), select the **Chat layout** icon in the top bar. It sits immediately to the left of the **Theme** icon. The compact panel opens below the icon and applies changes to the current Gemini page as you adjust them.

## How to Use It

1. Open [gemini.google.com](https://gemini.google.com) and select **Chat layout** in the top bar, immediately left of **Theme**.
2. For **Chat Width** and **Input Width**, choose **Default**, **%**, or **px**.
3. When using **%**, set a value from `35%` to `100%`. When using **px**, set a value from `700px` to `2000px`.
4. Turn on **Sync Chat Width and Input Width** if both areas should stay aligned.
5. Under **User messages**, choose left or right alignment and optionally enable **Allow full-width messages**.
6. Return a width control to **Default** whenever you want Gemini's native maximum width for that area.

Changes appear immediately and are kept for future Gemini pages. Switching a width to Default removes only that width override; it does not erase the last percentage or pixel value you chose.

## Turn the Top-bar Shortcut On or Off

The **Chat layout** shortcut is shown by default. To hide or restore it:

1. Open the Gemini Power Kit settings panel in Gemini.
2. Open **Settings** and then **Enhancements**.
3. Under **Top bar customization**, turn **Show Chat layout shortcut** off or on.

Turning this switch off only hides the top-bar icon and closes its open panel. It does not reset your Chat layout choices or stop them from applying. You can always manage the same controls from **Settings** → **Theme** → **Chat layout**, then turn the shortcut back on whenever you want faster access.

## Important Notes

- Chat layout changes maximum widths; the available viewport can still make the visible area smaller.
- **Default** preserves Gemini's native width for that control.
- This version does not change font size or line height.
- Gemini's interface can change over time. Keep Gemini Power Kit updated for the latest compatibility fixes.
