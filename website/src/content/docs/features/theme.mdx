## Overview

Theme is a Gemini theme customizer inside the Gemini Power Kit Chrome extension for Google Gemini. Use this if you want to customize Gemini's theme, add wallpaper, tune Light or Dark mode, and keep long sessions readable without leaving the Gemini interface.

Instead of only changing colors, it gives you three layers of control:

- appearance mode
- color presets
- wallpaper and readability tuning

## Interactions

### Theme Bloom

**Theme Bloom** turns a single image drop into a complete theme change. Drop an image anywhere on the Gemini page outside the prompt box, and Gemini Power Kit analyzes its colors, chooses the closest Theme color preset, saves the image as wallpaper, and reveals the new look from the drop point.

Theme Bloom is enabled by default. It accepts one `PNG`, `JPG`, `WebP`, or `AVIF` image up to `10MB` and `40MP`.

### How to Use Theme Bloom

1. Open Gemini Power Kit's **Settings** and select **Theme**.
2. Under **Interactions**, make sure **Theme Bloom** is on.
3. Drag one supported image from your computer onto any Gemini page area outside the prompt box.
4. Release the image when the Theme Bloom drop cue appears. The image becomes wallpaper, and the closest matching color preset is applied.
5. To attach an image to a Gemini prompt instead, drop it inside the prompt box. Gemini's native upload flow keeps handling that area.

### Turn Theme Bloom Off

Open **Settings** → **Theme** → **Interactions**, then switch **Theme Bloom** off. External image drops will no longer apply a theme. Image drops inside the prompt box continue to use Gemini's native upload behavior.

If an image is invalid, contains more than one file, or exceeds the size or dimension limit, Theme Bloom leaves the current theme and wallpaper unchanged.

## Why It Matters

Default Gemini styling works for short chats, but longer sessions usually expose a few friction points:

- you may want Gemini to stay in Light or Dark instead of following the current device state
- the default color system can feel too plain when you keep many tabs open every day
- wallpaper improves atmosphere, but it can also reduce contrast if readability controls are missing
- centered wallpaper cropping can hide the part of an image you wanted to keep visible

Theme solves those issues inside one settings panel, with live preview and automatic saving.

### Colors

`Colors` lets you switch between 10 preset swatches, including the default blue style and stronger alternatives like gray, red, cyan, teal, green, yellow, and orange.

Use it when:

- you want a clearer accent color for buttons, outlines, and active states
- you want Gemini tabs to feel visually distinct from other AI tools
- you want Light or Dark mode to feel less flat without changing layout behavior

## Default Behavior

When you first use Theme and wallpaper-related settings, the current defaults are:

- appearance is `System`
- color is the default Gemini blue
- Theme Bloom is `on`
- wallpaper is `off`
- blur starts at `0px`
- `Background Position` starts at `Center`
- `Message Glass Effect` is `on`
- `Sidebar readability scrim` is `on`
- `Scrim intensity` starts at `20%`
- `Welcome greeting readability` starts at `Auto adapt (first estimate)`

## Recommended Use

- For a clean everyday setup: `System` + a preset color + no wallpaper.
- For a branded personal workspace: `Light` or `Dark` + preset color + wallpaper.
- For Light mode with wallpaper: choose a `Background Position`, turn on `Sidebar readability scrim`, keep `Welcome greeting readability` on `Auto adapt (first estimate)`, then raise `Blur` if content still feels busy.
- For the best balance between style and clarity: choose a softer wallpaper, keep blur moderate, and only enable `Force light text` when the homepage greeting is still hard to read.

## Quick Workflow

1. Open Gemini Power Kit sidebar.
2. Go to `Settings` -> `Theme`.
3. Choose `Appearance` first so Light or Dark behavior is stable.
4. Pick a color preset that fits your daily workflow.
5. If you want wallpaper, enable it and upload one image.
6. Adjust `Background Position` and `Blur`, then turn on readability helpers only where needed.
7. Use the live preview to check contrast before returning to chat.
