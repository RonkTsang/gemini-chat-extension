Gemini Power Kit is a free, open-source browser extension for [Google Gemini](https://gemini.google.com). It adds tools such as Chat Outline, Quick Follow-up, themes, and chat width controls to the Gemini website.

For everyday use, install it from your browser's official store.

<LinkButton href="https://chromewebstore.google.com/detail/ihakfpnmefdkllhkecanagmienfnmojn" icon="external">Add to Chrome — Free</LinkButton>
<LinkButton href="https://addons.mozilla.org/en-US/firefox/addon/gemini-power-kit/" variant="secondary" icon="external">Get for Firefox</LinkButton>

## Install in Google Chrome

1. Open the [Gemini Power Kit listing in the Chrome Web Store](https://chromewebstore.google.com/detail/ihakfpnmefdkllhkecanagmienfnmojn).
2. Select **Add to Chrome**, review the permissions, and confirm with **Add extension**.
3. Open [gemini.google.com](https://gemini.google.com). If Gemini was already open, reload that tab.

You do not need Developer mode for the store version.

## Install in Mozilla Firefox

Use Firefox 140 or later, as required by the extension's Firefox build.

1. Open the [Gemini Power Kit listing on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/gemini-power-kit/).
2. Select **Add to Firefox**, review the permissions, and confirm the installation.
3. Open [gemini.google.com](https://gemini.google.com), or reload an existing Gemini tab.

## Open Settings and Confirm Installation

At the bottom of Gemini's sidebar, select the **Gemini Power Kit** puzzle-piece icon beside Gemini's Settings control. This opens the extension's settings inside Gemini.

Opening the settings panel confirms that the extension is running on that Gemini page. Choose the features you want to use; some enhancements need to be enabled in settings. See the [Quick Start guide](/guide/quick-start/) for the settings panel and your first actions.

For a specific task, continue with [changing Gemini's background](/tips/change-gemini-background/) or [adjusting chat and input widths](/features/chat-layout/).

## If the Extension Does Not Appear

- **Gemini was open before installation:** reload the Gemini tab after installing or updating the extension.
- **The settings entry is missing:** check that Gemini Power Kit is enabled in `chrome://extensions` or Firefox's `about:addons`, and that it is installed in the browser profile where Gemini is open. If you restricted its site access, allow it to run on `gemini.google.com`.
- **Settings open, but a feature is missing:** check that feature's settings and [feature guide](/features/). An optional feature being off does not mean installation failed.
- **Still having trouble:** use the [support page](/support/) and include your browser, extension version, and the steps that failed.
