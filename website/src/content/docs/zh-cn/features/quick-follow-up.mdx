<strong>划词追问（Quick Follow-up）</strong>让你读到哪里，就在哪里记下问题，再接着读。准备好后，把问题连同原文一起发给 Gemini，不用一直记着，也不用回头翻找、重新解释你问的是哪一段。

## 1. 选中一个点，点击 Ask Gemini

启用 Gemini Power Kit 后，打开 [gemini.google.com](https://gemini.google.com)，在回答中选中需要追问的文字，再点击浮动菜单中的<strong>询问 Gemini（Ask Gemini）</strong>。

<img src={entryDemo.src} alt="在 Gemini 回答中划词后，浮动菜单显示 Ask Gemini 和已保存的提示词图标" class="feature-image feature-image-narrow feature-image-full" />

*划词入口——选中需要深挖的内容，点击<strong>询问 Gemini</strong>。*

## 2. 直接在原文旁写下问题

点击 Ask 后，<strong>所选文字旁边</strong>会打开一个即时评论输入框，Gemini 主输入框上方也会新增一张引用卡片。你可以在阅读位置直接提问，无需先滚动到页面底部。

输入针对这段文字的问题，例如“可以给一个具体例子吗？”。点击<strong>勾号</strong>或按 <strong>Enter</strong>，把评论添加到对应卡片，暂不发送。按 <strong>Shift+Enter</strong> 可以换行。

### 按住 Command / Ctrl，从“添加”切换为“发送”

默认的勾号表示<strong>添加评论</strong>。在 macOS 按住 <strong>Command（⌘）</strong>，或在 Windows/Linux 按住 <strong>Ctrl</strong>，按钮会变成向上的<strong>发送箭头</strong>；松开后恢复勾号。

保持按住该键并点击箭头，或直接按 <strong>⌘+Enter / Ctrl+Enter</strong>，即可添加当前评论并发送整份草稿。这里会发送<strong>所有引用、各自的评论和主输入框内容</strong>，包括之前添加的卡片。

| 新增评论时的操作 | 行为 |
| --- | --- |
| <strong>Enter</strong> 或点击勾号 | 添加评论，继续准备草稿 |
| <strong>Shift+Enter</strong> | 换行 |
| <strong>⌘+Enter / Ctrl+Enter</strong>，或按住对应键点击发送箭头 | 添加当前评论并发送整份草稿 |

这些快捷键用于<strong>新增评论</strong>。重新打开已有评论时，请使用<strong>保存</strong>提交修改。

## 3. 继续选取其他内容，为每段添加评论

继续阅读，选中另一个需要追问的点，再次点击 <strong>Ask Gemini</strong>，为这段内容填写问题。已有卡片、评论和主输入框中的文字都会保留，让你先逐段收集问题，再一起发送。每份草稿最多添加 <strong>10 段引用</strong>。

准备好后，可以在 Gemini 主输入框中补充总体要求，例如“请逐段回答，每段给一个实际例子”。检查卡片后点击 Gemini 的<strong>发送</strong>按钮，所有引用、各自的评论和总体要求会一起发出。

每段评论和总体要求都可以留空。卡片会省略较长的预览以节省空间，实际发送时仍包含完整原文和评论。

## 4. 在已发送消息中回看问题与引用

发送后，所选原文和对应评论会保留在消息卡片中，总体要求也会一起展示。阅读 Gemini 的后续回答时，你可以回看每个问题针对的是哪段内容。

已发送的卡片为只读。下面的二次编辑入口用于仍在准备、尚未发送的评论。

## 从评论卡片再次打开编辑

1. 在主输入框中，将鼠标移到已有评论的卡片上，点击<strong>编辑图标</strong>；也可以点击卡片的评论入口。
2. 划词追问会返回原文位置，高亮对应文字，并在附近打开已有评论。
3. 修改后点击<strong>保存（Save）</strong>。对应卡片会更新，其他卡片和总体要求保留。

## 也可以点击原文旁的编号 marker 修改评论

添加引用后，原文旁会出现一个小型编号标记（<strong>marker</strong>），与卡片中的编号对应。阅读回答时，你可以直接从原文修改问题，无需先找到输入框里的卡片。

1. 找到需要修改的原文旁的编号，例如 <strong>1</strong>。
2. 将鼠标移到 marker 上，高亮对应的原文，确认它关联的是哪段内容。
3. 点击 marker，在原文旁重新打开这段评论。
4. 修改问题并点击<strong>保存（Save）</strong>，再检查对应卡片中的评论已更新。

点击<strong>取消（Cancel）</strong>、按 <strong>Esc</strong> 或点击外部，可以放弃本次未保存的编辑。修改评论不会改写引用原文。若要移除待发送的引用及其评论，点击卡片上的 <strong>×</strong>；剩余卡片会重新编号，主输入框中的要求会保留。

## 为重复操作保存自定义提示词

<strong>自定义提示词</strong>是一段可重复使用的指令，其中包含代表所选文字的占位符。在设置中，这些提示词以<strong>技能</strong>的形式管理。

1. 在 Gemini 左侧导航中，点击 <strong>Gemini Power Kit</strong>。
2. 在 <strong>Prompt（提示词）</strong>分组中打开<strong>划词追问</strong>。
3. 在<strong>技能管理</strong>中点击<strong>添加技能</strong>（`+`）。
4. 选择图标，填写不超过 30 个字符的名称和<strong>提示词内容</strong>。模板中需保留<strong>选中的文本（Selected Text）</strong>占位符，运行时会替换为你划选的文字。
5. 点击<strong>保存</strong>。回到对话，选中文字后点击对应技能图标即可使用。

例如，翻译技能可以写“将 [Selected Text] 翻译成日语，保留原文语气”，用<strong>选中的文本</strong>占位符替代方括号部分。代码审阅技能可以写“逐步解释 [Selected Text]，并指出边界情况”。

也可以点击<strong>一键添加常用模板</strong>，加入 <strong>Tell me more</strong>、<strong>Search</strong> 和 <strong>ELI5</strong>，并调整技能顺序，把常用操作排在前面。

### 点击技能后会发生什么

| 当前草稿 | 行为 |
| --- | --- |
| 没有引用卡片 | 展开提示词后自动发送。 |
| 已有引用卡片 | 选择<strong>添加到草稿（Add to draft）</strong>或<strong>分别发送（Send separately）</strong>。 |

<strong>添加到草稿</strong>：把替换好选中文字的完整提示词追加到主输入框末尾，保留已有卡片和评论，暂不发送。

<strong>分别发送</strong>：只发送本次技能展开后的提示词，暂存原来的引用草稿，并在 Gemini 清空输入框后恢复。如果扩展提示无法安全暂存草稿，请先发送或移除附件和带格式的内容，再重试。

## 开启或关闭划词追问

划词追问默认开启。在 <strong>Gemini Power Kit → Prompt（提示词）→ 划词追问</strong>中切换<strong>启用划词追问</strong>。

开启时会隐藏 Gemini 原生的 <strong>Ask</strong> 按钮，供你使用扩展的划词菜单；关闭后会恢复 Gemini 原生按钮。

## 使用限制

- 每份草稿最多添加 <strong>10 段引用</strong>。达到上限后，先移除一段再添加。
- 引用草稿只属于当前会话。切换会话会清理引用草稿，刷新页面也不会恢复。
- 回到原文需要对应文字仍在当前页面中可用，请勿依赖刷新后仍能使用来源编号跳转。
- 发送前检查引用和评论：它们会成为实际发给 Gemini 的消息内容。
